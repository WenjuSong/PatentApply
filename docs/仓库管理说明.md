# Git与公开仓库

远端：[WenjuSong/PatentApply](https://github.com/WenjuSong/PatentApply)，公开仓库。

## 精确白名单

只跟踪规则、通用文档、匿名模板、依赖清单、当前生成器、Skill导出脚本及明确列举的Skill发布文件。`.gitignore`默认忽略新文件，不用 `templates/*.json` 一类通配符放行可能存真实值的目录。

本地保留且不上传：原图、成品、PDF、截图、身份与签字、OCR/会话、台账、回执、真实配置、hash清单和其他业务数据；cases、output、tmp与历史版权材料均不入库。Git忽略不删除本地数据。

Skill维护源在本机个人Skill目录，仓库副本只运行 `scripts/export_skill.py` 导出；不能同时手改两份。公开文档不写个人姓名、身份号码、申报号、账号令牌、私密绝对路径或具体作品档案。

## 提交检查

1. 查看工作区差异，只添加本次明确路径，不用 `git add .`。
2. 查看暂存文件名、体积及完整diff；确认无个人资料、媒体、秘密或本机用户名路径。已有跟踪文件也须检查，ignore不能阻止其内容泄漏。
3. 校验匿名模板、链接、导出一致性及变更对应的实际输出。
4. 核远端与分支；获得推送授权后普通推送，不force。远端有新提交先拉取检查。

不使用 `git clean -fdx`。误跟踪文件用 `git rm --cached` 保留本地；已泄漏秘密需要单独处理，后续删除不消除历史。

公开克隆不包含本地索引、身份和素材；用户按授权补齐。公开配置有意保留“待填”，禁止未经替换直接作为申请材料使用。
