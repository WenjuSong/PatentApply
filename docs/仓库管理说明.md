# Git 与 GitHub 管理

远端：[WenjuSong/PatentApply](https://github.com/WenjuSong/PatentApply)，公开仓库。

## 跟踪范围

`.gitignore`采用白名单，只版本管理项目规则、通用操作文档、匿名示例配置、依赖清单和当前PDF生成器。新文件默认忽略；需要共享时先检查内容，再明确加入白名单。

以下仅本地保留：原始照片、成品图、PDF及其他二进制材料；cases、output、tmp；个人申请台账、原始会话与OCR、身份证明、签字确认函、申报回执、真实配置与校验产物。排除Git不会删除本地文件。

公开示例配置位于 `templates/`，没有真实姓名、申报号或发布记录；本地已确认模板继续保留原目录。公开示例是使用入口，不取代本地已确认事实与说明。

## 日常提交

1. 查看 `git status --short` 与 `git diff`，仅添加本次需要的明确路径。
2. 查看 `git diff --cached --stat`、`git diff --cached` 和 `git ls-files`，确认没有原件、个人资料或凭据。
3. 提交后，在有推送授权时执行 `git push`。远端有新提交先拉取检查，不强制覆盖。
4. 不使用 `git clean -fdx` 清理本项目：被忽略目录包含需要长期保留的业务文件。

如需从Git移除误跟踪文件，保留本地数据并用 `git rm --cached`；已推送的敏感数据不能只靠后续删除消除历史，应单独处理。
