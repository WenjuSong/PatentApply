# 材料与写作

## 事实与模板入口

读项目 `docs/模板与资料索引.md`：它指向已确认范本、当前匿名文字模板、PDF配置及共用研发素材。没有项目索引时，核对作品名、作者与权属、原创照片及拍摄日期、本人确认的成品、实际调用与艺术决定、完成/发表时间地点及证据。文件名含approved、修改时间或AI报告不代替本人确认。

Tianbiao首次公开平台默认小红书，每件仍核对应帖子与日期；年份不能只从“09-13”推断。名称按原创插画，发表截图中的原题与用途字样保持原貌。权属已有确认且无变化线索时沿用；有矛盾再问。

## 少改文字

| 内容 | 复用方式 |
|---|---|
| 个人背景、创作工作流、Skill研发及AI分工 | 沿用已确认段落，只有实际事实变化才修改 |
| 本件画面 | 主体关系、风格及情绪用一至两句说明；不逐个罗列细节 |
| 本件过程 | 日期、调用及一项有记录的调整；直接调用不编造调试经历 |
| 完成与发表 | 核本件时间地点、规格及发布证据，不能复制前件日期 |
| 摄影图说明 | 采用配置中的来源句，只换拍摄日期和主题，不再描述可见元素 |

用自然准确的“本人运用自主设计开发的……”“原创素材拍摄”“本人主导Skill工具方案设计”。不把个人贡献概括成仅仅选择成品，不强调“选定”“初版”，也不将无实际调整包装成调整。无艺术指导记录时缩减相应句子。风格描述必须与画面相符，不杜撰名称。

共同研发可作为多件作品的背景，不能写成每件重新开发。保留真实时间的研发证据，必要时标题说明为共用资料；不将晚于单件完成的研发写成当时已使用。内部核对记录放档案，正式PDF以申请人立场面向审查人员，避免整理备注和无必要解释。

原创/改编不是是否使用AI的同义词。按事实及当前页面处理，不机械因照片转插画填改编，也不保证有原创照片就必然获证。区分风格研究参考与实际生成输入；不明权利来源列缺项。

## 平台文字检查

2026-10-22观察的栏位上限：中心内容及特点600字（分项提示400/200）、著作权人简介400字、创作过程1000字、首次发表形式200字。当前页面优先；可同时统计Python字符数及UTF-16长度，再读回确认未截断。

过程标题须独立换行：`1.创作意图：`、`2.创作方法：`、`3.具体过程：`。标题遵守平台校验，正文可用“创作流程”。未发表时过程结尾与第四部分一起改为未发表，不留虚构日期网址。作者本人确认文字后才填写；工作单位等缺项不编造。

## 文件

- 作品：从本人确认的PNG复制、转换JPG；不用社交预览代替成品。需要作品名、作者、权利人标注时放画外，不遮原画。不加水印，平台水印与本地文件分别核验。
- 补充PDF：四项分行综述，然后原创摄影、AI Skill开发、插画制作、首次发布四部分。Tianbiao完整保留九张共用研发图，每图一句；其他项目按证据事实设置，不将九图当官方要求。单件过程图据实变化，总页数不固定。未发表第四部分为无图的状态说明。
- 图像完整等比放置，长截图检查可读性；低清证据优先回原网页重截，不靠放大或重绘日期。
- JPG/PDF本次页面上限10/30MB，下次核页面。源PNG副本hash一致；上传同名文件按角色分目录。
- PDF图片相对路径以配置文件所在目录解析，绝对路径迁移时统一核对。使用匿名配置的所有待填项必须替换；不为过校验删除缺项。

生成器：`python3 版权准备/补充材料PDF模板-北京-v2-20261022/build_pdf.py 配置.json 新输出目录`。依赖Pillow、reportlab、pypdf和中文字体；优先复用已验证环境。配置拒绝未填、发表冲突、缺图和覆盖；脚本成功不代替渲染检查或用户确认。

签字函的核对与上传见[网页协作](browser.md)。真实姓名、身份材料、签字、私密路径和回执只放本件档案，不带入公开示例或本Skill。
